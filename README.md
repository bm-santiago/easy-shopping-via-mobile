## 📱💻 Primeiro Projeto Responsivo

Este foi meu **primeiro projeto utilizando responsividade**, desenvolvido com **HTML5 e CSS3**.  
O objetivo foi criar uma interface simples e moderna, que se adaptasse corretamente a **diferentes tamanhos de tela**, como **desktop e dispositivos móveis**.

Durante o desenvolvimento, pratiquei conceitos importantes como:
- Estruturação semântica com **HTML**
- Estilização e organização de layout com **CSS**
- **Responsividade** utilizando media queries
- Ajustes visuais para melhorar a experiência do usuário em diferentes dispositivos

Esse projeto marcou meu início no desenvolvimento Front-End e representa um grande passo na minha evolução como desenvolvedor 🚀
